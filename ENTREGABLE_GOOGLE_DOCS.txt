1. estructura del proyecto

descripcion de la estructura:
el proyecto esta armado sobre una arquitectura en capas para una api de adopcion de mascotas en node.js con express. se dividen las responsabilidades entre controladores, servicios, repositorios y dao para manejar la coneccion con la base de datos mongodb. tambien se sumaron los tests aislados con mocks y la configuracion para dockerizar la aplicacion.

explicacion breve de archivos y carpetas principales:
- src/app.js: aca arranca el servidor de express, se configuran los middlewares, la ruta de la documentacion de swagger y la coneccion a la base de datos.
- src/routes/adoption.router.js: contiene los endpoints para obtener y crear adopciones.
- src/controllers/adoptions.controller.js: maneja la logica de las peticiones que llegan del router de adopciones.
- src/services/ e index.js: instancian los servicios que conectan los controladores con los repositorios.
- src/repository/: capa de abstraccion que implementa el patron repository.
- src/dao/: objetos de acceso a datos que interactuan directo con los esquemas de mongoose.
- test/adoption.test.js: suite con los tests funcionales para probar los endpoints de adopciones simulando las respuestas de la base de datos.
- Dockerfile: instrucciones para construir la imagen optimizada de docker.


2. tests funcionales

codigo completo de los tests funcionales (test/adoption.test.js):

import request from 'supertest';
import { expect } from 'chai';
import sinon from 'sinon';
import app from '../src/app.js';
import { adoptionsService, petsService, usersService } from '../src/services/index.js';

describe('Suite de Tests Funcionales - Router Adoptions (/api/adoptions)', () => {

    afterEach(() => {
        sinon.restore();
    });

    describe('GET /api/adoptions', () => {

        it('Debería retornar un status 200 y la lista completa de adopciones (Caso Exitoso)', async () => {
            const mockAdoptions = [
                { _id: '647fa8c9e46dbc5a20320199', owner: '647fa8c9e46dbc5a20320181', pet: '647fa8c9e46dbc5a20320182' },
                { _id: '647fa8c9e46dbc5a20320200', owner: '647fa8c9e46dbc5a20320183', pet: '647fa8c9e46dbc5a20320184' }
            ];

            sinon.stub(adoptionsService, 'getAll').resolves(mockAdoptions);

            const response = await request(app).get('/api/adoptions');

            expect(response.status).to.equal(200);
            expect(response.body).to.have.property('status', 'success');
            expect(response.body.payload).to.be.an('array');
            expect(response.body.payload).to.deep.equal(mockAdoptions);
        });

        it('Debería retornar status 200 y un array vacío cuando no existen adopciones registradas', async () => {
            sinon.stub(adoptionsService, 'getAll').resolves([]);

            const response = await request(app).get('/api/adoptions');

            expect(response.status).to.equal(200);
            expect(response.body).to.have.property('status', 'success');
            expect(response.body.payload).to.be.an('array').that.is.empty;
        });

        it('Debería manejar errores del servidor retornando status 500', async () => {
            sinon.stub(adoptionsService, 'getAll').rejects(new Error('Database connection failed'));

            const response = await request(app).get('/api/adoptions');

            expect(response.status).to.equal(500);
            expect(response.body).to.have.property('status', 'error');
            expect(response.body.error).to.equal('Database connection failed');
        });

    });

    describe('GET /api/adoptions/:aid', () => {

        it('Debería retornar status 200 y el objeto de adopción al enviar un ID válido existente', async () => {
            const mockAdoption = {
                _id: '647fa8c9e46dbc5a20320199',
                owner: '647fa8c9e46dbc5a20320181',
                pet: '647fa8c9e46dbc5a20320182'
            };

            sinon.stub(adoptionsService, 'getBy').resolves(mockAdoption);

            const response = await request(app).get('/api/adoptions/647fa8c9e46dbc5a20320199');

            expect(response.status).to.equal(200);
            expect(response.body).to.have.property('status', 'success');
            expect(response.body.payload).to.deep.equal(mockAdoption);
        });

        it('Debería retornar status 404 con error "Adoption not found" si el ID de adopción no existe', async () => {
            sinon.stub(adoptionsService, 'getBy').resolves(null);

            const response = await request(app).get('/api/adoptions/nonexistentid123');

            expect(response.status).to.equal(404);
            expect(response.body).to.have.property('status', 'error');
            expect(response.body.error).to.equal('Adoption not found');
        });

        it('Debería retornar status 500 ante un error interno en la búsqueda por ID', async () => {
            sinon.stub(adoptionsService, 'getBy').rejects(new Error('Internal lookup error'));

            const response = await request(app).get('/api/adoptions/errorId');

            expect(response.status).to.equal(500);
            expect(response.body).to.have.property('status', 'error');
        });

    });

    describe('POST /api/adoptions/:uid/:pid', () => {

        it('Debería realizar la adopción con éxito (status 200) cuando el usuario y la mascota existen y la mascota no está adoptada', async () => {
            const mockUser = {
                _id: '647fa8c9e46dbc5a20320181',
                first_name: 'Juan',
                last_name: 'Pérez',
                pets: []
            };

            const mockPet = {
                _id: '647fa8c9e46dbc5a20320182',
                name: 'Firma',
                specie: 'Dog',
                adopted: false
            };

            sinon.stub(usersService, 'getUserById').resolves(mockUser);
            sinon.stub(petsService, 'getBy').resolves(mockPet);
            sinon.stub(usersService, 'update').resolves(true);
            sinon.stub(petsService, 'update').resolves(true);
            sinon.stub(adoptionsService, 'create').resolves({ _id: '647fa8c9e46dbc5a20320199', owner: mockUser._id, pet: mockPet._id });

            const response = await request(app).post(`/api/adoptions/${mockUser._id}/${mockPet._id}`);

            expect(response.status).to.equal(200);
            expect(response.body).to.have.property('status', 'success');
            expect(response.body.message).to.equal('Pet adopted');
        });

        it('Debería retornar status 404 con "user Not found" si el usuario no existe', async () => {
            sinon.stub(usersService, 'getUserById').resolves(null);

            const response = await request(app).post('/api/adoptions/invalidUserId/647fa8c9e46dbc5a20320182');

            expect(response.status).to.equal(404);
            expect(response.body).to.have.property('status', 'error');
            expect(response.body.error).to.equal('user Not found');
        });

        it('Debería retornar status 404 con "Pet not found" si la mascota no existe', async () => {
            const mockUser = {
                _id: '647fa8c9e46dbc5a20320181',
                first_name: 'Juan',
                pets: []
            };

            sinon.stub(usersService, 'getUserById').resolves(mockUser);
            sinon.stub(petsService, 'getBy').resolves(null);

            const response = await request(app).post(`/api/adoptions/${mockUser._id}/invalidPetId`);

            expect(response.status).to.equal(404);
            expect(response.body).to.have.property('status', 'error');
            expect(response.body.error).to.equal('Pet not found');
        });

        it('Debería retornar status 400 con "Pet is already adopted" si la mascota ya fue adoptada', async () => {
            const mockUser = {
                _id: '647fa8c9e46dbc5a20320181',
                first_name: 'Juan',
                pets: []
            };

            const mockAdoptedPet = {
                _id: '647fa8c9e46dbc5a20320182',
                name: 'Firma',
                adopted: true
            };

            sinon.stub(usersService, 'getUserById').resolves(mockUser);
            sinon.stub(petsService, 'getBy').resolves(mockAdoptedPet);

            const response = await request(app).post(`/api/adoptions/${mockUser._id}/${mockAdoptedPet._id}`);

            expect(response.status).to.equal(400);
            expect(response.body).to.have.property('status', 'error');
            expect(response.body.error).to.equal('Pet is already adopted');
        });

        it('Debería retornar status 500 ante un fallo durante el proceso de actualización', async () => {
            const mockUser = { _id: 'user123', pets: [] };
            const mockPet = { _id: 'pet123', adopted: false };

            sinon.stub(usersService, 'getUserById').resolves(mockUser);
            sinon.stub(petsService, 'getBy').resolves(mockPet);
            sinon.stub(usersService, 'update').rejects(new Error('Failed to update user'));

            const response = await request(app).post('/api/adoptions/user123/pet123');

            expect(response.status).to.equal(500);
            expect(response.body).to.have.property('status', 'error');
        });

    });

});

explicacion de lo que valida cada grupo de tests:

- GET /api/adoptions: testea que se devuelvan todas las adopciones guardadas con estado 200, que responda un array vacio cuando no hay registros, y que devuelva status 500 en caso de falla interna.
- GET /api/adoptions/:aid: valida buscar una adopcion por su id. chequea que responda 200 con el objeto si existe, 404 si no se encuentra el registro y 500 ante un fallo inesperado.
- POST /api/adoptions/:uid/:pid: valida el proceso de adopcion. verifica que se cree bien relacionando usuario y mascota (200), que valide si el usuario no existe (404), si la mascota no existe (404) o si la mascota ya habia sido adoptada previamente (400).

3. dockerizacion

contenido completo del dockerfile:

FROM node:20-alpine AS base

WORKDIR /app

COPY package*.json ./

RUN npm ci --only=production && npm cache clean --force

COPY . .

USER node

EXPOSE 8080

ENV NODE_ENV=production
ENV PORT=8080

CMD ["node", "src/app.js"]

explicacion de decisiones de optimizacion:
- use la imagen base node:20-alpine por ser super liviana y rápida.
- copie primero los package.json para aprovechar la memoria cache de docker cuando no cambian las librerias.
- use npm ci --only=production para instalar solo lo necesario de produccion sin instalar moch o chai.
- pase el usuario a "USER node" por seguridad para no correr la aplicacion como root.
- agregue un archivo .dockerignore para evitar copiar carpetas pesadas o innecesarias como node_modules o .git.

# proyecto final backend III - patitas api

este es el proyecto final para la materia de backend 3. consiste en una api en nodejs y express para la gestion de adopciones de mascotas, usuarios y sesiones. cuenta con documentacion swagger, pruebas funcionales con mocks y una imagen docker optimizada.

## links de la entrega

- repo de github: https://github.com/Mike-Camus223/proyecto-final-backend3
- imagen en dockerhub: https://hub.docker.com/r/mikedev1423/patitas-api

## estructura basica

- src/app.js: entrada principal de la app express y conexion a mongodb.
- src/routes/adoption.router.js: las rutas para ver y crear adopciones.
- src/controllers/: la logica de las peticiones para adopciones, usuarios y mascotas.
- src/services/ y src/repository/: capa de servicios y repositorios.
- src/dao/: acceso a la base de datos con los modelos de mongoose.
- test/adoption.test.js: los tests funcionales hechos con mocha, chai, supertest y sinon.
- Dockerfile: el archivo para armar la imagen ligera del proyecto.

## como ejecutar el proyecto localmente

1. clonar el repo e instalar dependencias:
npm install

2. crear el archivo .env basandote en el .env.example

3. levantar el servidor en modo desarrollo:
npm run dev

la api queda corriendo en http://localhost:8080 y la documentacion de swagger la podes ver en http://localhost:8080/api/docs

## como correr los tests funcionales

para probar las rutas de adopcion con los mocks (sin usar la base de datos real):
npm test

## como construir y correr en docker

1. construir la imagen:
docker build -t mikedev1423/patitas-api:1.0.0 .

2. correr el contenedor:
docker run -d -p 8080:8080 --name patitas-container mikedev1423/patitas-api:1.0.0

3. subir la imagen a dockerhub:
docker push mikedev1423/patitas-api:1.0.0
docker tag mikedev1423/patitas-api:1.0.0 mikedev1423/patitas-api:latest
docker push mikedev1423/patitas-api:latest
